Chord Sheet Builder

Fill in beats and chords — alignment is handled for you.

Two ways to save:
  • Save draft — temporary backup in this browser while you transcribe. Won’t appear on the site.
  • Save .md — the real song file for _songs/. Commit and push to publish on the site.
  • Section repeat — use the section Repeat field (e.g. 2x) to play that whole section twice. Saved as III 2x.
  • Line repeat — use Repeat on a chord line to play that sequence again (e.g. E-A three times saves as E - A - 3x, then continue with the next line).
  • Repeat line — check Repeat instruction only, then add sections one by one (like chords). Optional Repeat on each (e.g. I + 2x → I (2x) - II).
  • Slash chords — use C/G for chord-over-chord (formats as C/G, Am/G, etc.).
  • Copy / paste line — use Copy line on a row, then Paste line on another to duplicate beats and chords quickly.

Section labels are whatever you type in Numeral — roman (I, II) or a name (Verse 1, Intro). The site shows your labels as-is.
